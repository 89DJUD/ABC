# Analyse ABC multicritère des stocks

Devoir libre EMI (Prof. Lamrani) : classification ABC de 700 articles par TOPSIS, machine learning et Fuzzy TOPSIS.

- `devoir_ABC_multicritere.ipynb` : notebook complet répondant aux questions 1 à 10
- `streamlit_app.py` : interface interactive

## Lancer l'interface

```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Pages : données · TOPSIS et ABC (poids et seuils réglables) · machine learning (comparaison des modèles, classement d'un nouvel article) · approche floue.
